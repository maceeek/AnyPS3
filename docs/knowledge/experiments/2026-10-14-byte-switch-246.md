## Reproduction and provenance

**Verified:** the real `native-virtual-245` ended at `0x69dd30`, LR
`0x69dabc`, CTR `0x69dd30`, r0=r27=13, r7=`0x69db38`, r10=`0x34`,
r3=r6=`0x1f8`; FPSCR `0x86002000`. The game returncode 1, session 6682 terminated.
The run's own verification and the independent terminal-identity document the original PT_LOAD
and the artifact/diagnostic hashes. Frame 33 still the loading planet.

The evidence `local/ratchet/target-246-evidence.json` contains the original words,
all offsets, targets, entry bytes and the ELF SHA256
`6debdca0f181f35d98ebe23faabe2531b697c558b4e3384b06630173400674c1`.
The original TOC load `0x69d6d8`, word `83c2b0ec`: r30 is loaded from
TOC `0xd34a88` − `0x4f14` = cell `0xd2fb74`, value `0xcacf80`.
The original `lwz r7,-0x7f58(r30)` at `0x69db1c` loads cell `0xca5028`,
which contains the base `0x69db38`.

The `lbz` at `0x69db10` reads an unsigned-byte index. `cmplwi cr7,r0,13` and
`bgt cr7` at `0x69db14/18` limit the index to 0..13 (otherwise `0x69dd78`).
The `rlwinm` at `0x69db20` produces index×4 with mask `0x3fc`; `lwzx`,
`extsw`, `add`, `mtctr`, `bctr` at `0x69db24..34` load a signed
big-endian int32 offset, add the table base and jump to a code block.
The table has 14 entries and 12 unique targets, all aligned/executable.
Slot 13 at `0x69db6c`: offset `0x1f8` → observed `0x69dd30`.
This is not a new indirect function or OPD, but an internal case block.

**Decision:** add the exact verified table to the profile. The automatic
detector has a strict canonical `rldic` pattern and does not accept this byte-indexed `rlwinm`
pattern; this is not permission to skip the original branch or change data.
