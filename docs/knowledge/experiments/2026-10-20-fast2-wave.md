## Measurement 470a

`local/ratchet/tools/measure_level.sh 470 470a ANYPS3_RSX_HOST_PROFILE=1` (same script, scene and window as 380base/386a/460a),
with `nvidia-smi` sampled every 500 ms into `local/ratchet/gpu-clock-470a.csv`. Original menu → LOAD → `great_clock_a`, no STOP,
`level-frame.ppm` visually the same scene as 460a (only animated light beams/Clank pose differ).

| quantity | 460a | **470a** |
| --- | --- | --- |
| FPS mean / median / min / max | 22.59 / 23.0 / 13.9 / 25.5 | **29.70 / 29.97 / 27.4 / 30.4** |
| draws per frame | 989 | 1003 |
| RSX worker busy (ms/frame) | 28.3 | **22.9** |
| RSX gpu_wait / flip_wait | 4.1 / 8.7 | 1.4 / 7.1 |
| `PERF GPU busy` (ms/frame) | ~31 | **~13.0** |
| main thread ppu / idle / coordinator / audio | 16.9 / 23.2 / 3.6 / 0.5 | 13.9 / 17.9 / 1.8 / 0.1 |
| thread 1 instructions per frame, ns/instr | 17.6 M, 0.88 | 8.4 M, 1.53 |
| SPU instructions per frame | 28.9 M | 24.3 M |

GPU clocks during 470a: mostly P8 210 MHz and P3 ~950 MHz, short P0 2.6–2.9 GHz bursts (utilization ≤ 40%).

**Derived:** the cloud round gives +31% FPS in the game; the GPU time per frame fell by ~18 ms, consistent with the MSAA plane
runs hypothesis of the cloud record (not yet separated by an A/B run). Fewer guest instructions per frame on thread 1 at a
higher ns/instr means less busy-waiting (spin hints / SPU parking), not a slower PPU.
**Derived — VSYNC quantization:** in mode 0 the game flips on vblank (59.94 Hz), so the frame rate moves in steps; a median
of exactly 29.97 means most frames take two vblanks. 60 FPS needs every per-frame path (RSX worker CPU, GPU, main thread,
SPU jobs on the critical path) under 16.7 ms, with headroom ~13 ms. The RSX worker (22.9 ms) is the first limit; the main
thread (15.8 ms busy) is at the budget edge; the GPU (13 ms at low clocks) is inside it.

## Wave organization

Three Sonnet 5.5 (effort xhigh) subagents in git worktrees `local/ratchet/work/<task>/tree` on branches `fast2/<task>`
(tool `local/ratchet/tools/make_gitworktree.sh`; `base/` = snapshot 470 for `agent_build.sh`), common rules
`local/ratchet/work/COMMON-FAST2.md`, tasks `local/ratchet/work/<task>/TASK.md`:

- **GPUFAST** (builds 480–499): GPU busy ≤ 8 ms/frame (occlusion queries, full barriers, render passes, MSAA, framebuffer cache).
- **RSXCPU** (500–519): RSX worker ≤ 10 ms/frame (per-draw CPU cost, alias readbacks, possibly a producer/consumer split).
- **CRITPATH** (520–539): main-thread busy ≤ 12 ms/frame (guest spin-waits on SPU jobs, SPU job latency, coordinator, PPU).

The main agent integrates (builds 470–479) and measures; full suite over 470: `local/ratchet/suite-470/`.
