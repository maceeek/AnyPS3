# Rozdělený C++ překlad a paralelní kompilace (256)

Datum 2026-10-15, Claude Opus 5.5. Cíl: původní menu ACIT a navigace gamepadem —
**zatím nedosaženo**. Tento záznam řeší hlavní brzdu vývoje: jediná ~458 MB
překladová jednotka (LTO ~7–15 min, 255 nedokompilováno).

## Změna (ověřené testy)

- `anyps3/program.py`: `Program._parts()` sdílí jeden generátor pro
  `cpp()` (jedna TU, testy beze změny) i `cpp_units(units=N)`:
  `anyps3.hpp` (typy, `PpuState`, čisté instrukční helpery FLOW/FLOAT/VECTOR/FS,
  deklarace), `program.cpp` (runtime služby, SPU dispatch, `anyps3_entry`, `main`),
  `ppu-NNN.cpp` (stránky po 4 KiB), `spu-NNN.cpp` (TLS+MMAPPER+SPU core helpery
  + SPU funkce). Jednotky se dělí souvisle podle kumulativní velikosti (≤ N souborů).
- Operace s `word==0` (importy, native module hooky, redirecty exportů) a `sc`
  se emitují jako externí `anyps3_op_<adresa>(PpuState&)` v `program.cpp`;
  stránka je jen volá. Sémantika těla je stejná (návrat z op funkce → `break`).
- `anyps3/spu.py:generate_parts`: stránka SPU s více než `SPU_FUNCTION_BODIES=1024`
  variantami (PC × přesné slovo z obrazu/overlayů) se dělí na menší rozsahy PC
  (`spu_image_I_page_P_SHIFT_CHUNK`) s malým dispatcherem. Guard přesného slova
  i stop „SPU target has no static translation“ zachovány.
- `anyps3/native_build.py`: `write_units` (+`units.json` s SHA-256),
  `unit_sources` (ověří hashe), `compile_units` (paralelní `c++ -c`, logy per unit,
  link). Všechny jednotky stejné flagy — layout `PpuState` závisí na `-DANYPS3_VULKAN`.
- `build_game.py --units` (výchozí 96) zapisuje jednotky místo jedné `program.cpp`.
- `local/ratchet/tools/virtual_pad.py build -j N`: u split bundle obalí jen
  `program.cpp` (main) a ostatní jednotky zkompiluje beze změny; `.o` smaže, logy ponechá.

Testy: `tests/test_split_units.py` (4): modulový import/export řetězec a syscall
výsledek/neznámý syscall přes oddělené jednotky; SPU stránka s 2048 variantami se
rozdělí na dvě 2KiB poloviny a vybírá přesná slova obou overlayů, neznámé slovo a
nepřeložené PC zastaví; změněná jednotka vůči `units.json` je odmítnuta.
Celá sada: 229 OK s `ANYPS3_REQUIRE_VULKAN=1` (`local/ratchet/tests-256.log`).
