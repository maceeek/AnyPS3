## Confirmed timer deadline fix

`anyps3/threads.py`: with active guest audio, the old branch slept 100 µs before computing the nearest
timer deadline. Now the host sleep is limited by the nearest deadline and the existing
cap of 100 µs with audio/1000 µs without audio; an expired deadline does not sleep. A native test of the real
ppu_schedule with deterministic time covers 11 scenarios including peer wake, kernel timeout,
notifications and nonexistent progress. Baseline RED, delivery and integrated test PASS;
logs `codex/pipe2/timer-{baseline-red,tests}.log`, `timer380-targeted.log`.
The targeted suite of 379 had 22/23 PASS; the outdated atexit oracle required a stop which 377 correctly
replaced with wait_kind 13. The fixed test preserves the callback order and checks the untouched state of the
blocked thread; module 2/2 PASS. Details `codex/audit379/atexit-test.patch` and the audit report.
