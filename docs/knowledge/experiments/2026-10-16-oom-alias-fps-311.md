## Cílové FPS hry (ověřené staticky, výběr v menu zatím neověřen)

Původní EBOOT (`local/ratchet/EBOOT.analysis.elf`), importy `cellGcmSetVBlankHandler`, `cellGcmSetFlipMode`,
`_cellGcmSetFlipCommandWithWaitLabel`. Struktura `G = *(0xca3f84) = 0xf6cb30` (BSS).

- VBlank handler OPD `0xd17890` → kód `0x661730`: pokud `G+24 (interval) != 0`, sníží `G+28`; při nule nastaví
  příznak `*(G+32)=1` a obnoví `G+28 = interval` → snímek povolen jednou za `interval` vblanků.
- Volič režimu `0x661c50(mode)`: `G+84 = mode`, mez `mode <= 5`, tabulka hned za `bctr` na `0x661c94`
  (`0x18,0x40,0x58,0x64,0x74,0x24` relativně k `0x661c94`):

  | mode | interval | `cellGcmSetFlipMode` | FPS při 59,94 Hz |
  | --- | --- | --- | --- |
  | 0 | 0 | 2 (VSYNC) | bez rámce, flip čeká na vblank → ≤ 59,94 |
  | 1 | 1 | 1 (HSYNC) | 59,94 |
  | 2 | 2 | 1 | 29,97 |
  | 3 | 3 | 1 | 19,98 |
  | 4 | 4 | 2 | 14,99 |
  | 5 | 0 | 1 | bez omezení |

- Volající: `0x32ad94` mode 2, `0x333db0` a `0x336550` mode 0, ostatní (`0x32ad18`, `0x334c4c`, `0x3364d0`,
  `0x5c8bc4`) z paměti. Log 309: `flip mode` 2 → 1 → 2 → 1 → 2 (poslední před menu = VSYNC, tj. mode 0 nebo 4).
- Runtime: vblank 60000/1001 Hz v reálném čase (`anyps3/rsx.py rsx_tick_vblank`), flip v režimu 2 čeká na další
  vblank. Diagnostika volajícího: `services.py` `cellGcmSetFlipMode` tiskne `native GCM flip mode callers lr=…`
  (back chain) → rozliší místo volání a tedy režim menu.
- **Hypotéza:** menu běží v mode 0 → cíl 59,94 FPS; ověří 311d.
